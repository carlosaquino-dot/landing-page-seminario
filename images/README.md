# Imágenes requeridas

Coloca aquí los siguientes archivos (mismos nombres y rutas que usa `index.html`):

| Archivo | Uso | Tamaño recomendado |
|---|---|---|
| `logo-emigrafacil.png` | Logo en el header, footer y favicon | PNG transparente, alto ~120px |
| `mar-carlos.jpg` | Foto destacada del Hero (Mar y Carlos juntos) | 1200×1500px (vertical, 4:5) |
| `carlos.jpg` | Foto individual de Carlos, sección "Ponentes" | 600×600px (cuadrada) |
| `mar.jpg` | Foto individual de Mar, sección "Ponentes" | 600×600px (cuadrada) |
| `equipo-emigrafacil.jpg` | Foto de equipo / banner de marca | 1200×900px |

Estas imágenes no se pudieron incrustar automáticamente en el repositorio:
súbelas manualmente a esta carpeta con los nombres exactos indicados arriba para
que se muestren correctamente en la landing.
